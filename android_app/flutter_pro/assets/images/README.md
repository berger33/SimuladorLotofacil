- splash.png 1080x1920 (splash screen)
- onboarding_1.png, onboarding_2.png, onboarding_3.png
- feature_graphic.png 1024x500 (Play Store)

Para gerar ícone com flutter_launcher_icons:
```bash
flutter pub run flutter_launcher_icons
```

Para splash:
```bash
flutter pub run flutter_native_splash:create
```
