================================================================================
                      SIMULADOR LOTOFÁCIL PRO - V2.0
                  RELATÓRIO TÉCNICO E MANUAL DO USUÁRIO
================================================================================

O "Simulador Lotofácil Pro" é uma aplicação desktop de alta performance, focada 
em análise preditiva, modelagem estatística e evolução genética de dezenas. 
Construído em Python, o sistema utiliza Processamento Paralelo (Multicore), 
Heurística de Poda e Ciência de Dados para encontrar as melhores matrizes 
matemáticas de 20 dezenas, com desdobramento para 33 jogos de 15 dezenas.

================================================================================
PARTE 1: FICHA TÉCNICA E ARQUITETURA DO SISTEMA (ENDPOINTS/MÓDULOS)
================================================================================

[1. ESTRUTURA DE ARQUIVOS]
- app.py                : Arquivo de inicialização. Contém a trava de 
                          multiprocessamento (freeze_support) para Windows.
- recuperar_base.py     : Script de manutenção para forçar o download limpo de 
                          todo o histórico da Caixa.
- ui/interface.py       : O "Cérebro Visual". Gerencia janelas, threads, gráficos,
                          limpeza de RAM e interações do usuário.
- core/genetic.py       : O "Motor Evolutivo". Cuida da criação de indivíduos, 
                          Cruzamento (Crossover) e Mutação de DNA matemático.
- core/evaluator.py     : O "Juiz". Simula anos de sorteios em frações de segundo, 
                          testando cada desdobramento gerado.
- core/fechamento.py    : A "Peneira". Transforma a base de 20 dezenas em 33 
                          apostas, eliminando jogos que não passam nos filtros.
- core/crawler.py       : O "Vigia". Conecta-se à API da Caixa para manter a 
                          base de dados atualizada.

[2. MOTORES E FUNCIONALIDADES TÉCNICAS]
-> Motor Genético (Algoritmo): Utiliza uma População de matrizes. As melhores 
   (Elite) cruzam suas dezenas e sofrem Mutações (1% a 2%) para encontrar 
   combinações cada vez mais lucrativas, fugindo de "becos sem saída".

-> Heurística de Poda (Filtros Ativos): Avalia cada uma das 33 cartelas geradas. 
   Se uma cartela violar as regras de Ímpares, Moldura ou Primos, ela é 
   descartada da memória antes de ser testada, poupando processamento.

-> Trava Anti-Overfitting (Segurança): O `evaluator.py` só utiliza os sorteios 
   reais para base de teste se o banco de dados tiver mais de 1000 concursos. 
   Caso contrário, testa 100% contra a matemática caótica, impedindo a IA de 
   "decorar" um sorteio e gerar lucros irreais.

-> Garbage Collector (Auto-Limpeza): A cada 10 gerações, a interface força o 
   Python a limpar o lixo de processamento na Memória RAM, permitindo que o 
   sistema rode 24 horas por dia, 7 dias por semana, sem travar o computador.

-> Integração Pandas (Exportação): Converte a base JSON em um DataFrame de alta 
   velocidade e exporta para CSV delimitado por ponto-e-vírgula (;), pronto para 
   leitura nativa no Microsoft Excel.

================================================================================
PARTE 2: MANUAL DO USUÁRIO (COMO OPERAR A MÁQUINA)
================================================================================

[A. VISÃO GERAL DA INTERFACE]
A tela é dividida em três setores principais:
1. Painel de Ações (Topo Esquerdo): Botões de Iniciar, Pausar, Parar e Turbo.
2. Tela Principal (Centro): Exibe o Log em tempo real, Listas, Top 3 e Gráficos.
3. Painel de Controle (Direita): Navegação, Filtros, Presets e Heatmap (Raio-X).

[B. CONFIGURANDO A SUA ESTRATÉGIA]
Antes de iniciar a simulação, você deve configurar os parâmetros no painel direito.

1. Filtros de Poda (Checkboxes):
   - Ímpares (7 ou 8): Força os jogos a terem a proporção mais comum de ímpares.
   - Moldura (9 a 11): Concentra as dezenas na borda do volante.
   - Primos (4 a 6): Regra de ouro da loteria.
   * Dica: Marcar todos os filtros cria jogos incrivelmente realistas, mas 
     pode tornar a evolução ligeiramente mais lenta (a IA trabalha mais).

2. Dezenas Bloqueadas (Lista Negra):
   - Digite os números separados por vírgula (Ex: 3, 15, 22).
   - O algoritmo é estritamente proibido de inserir essas dezenas na Base de 20.

3. Gerenciador de Presets (Perfis):
   - Montou uma configuração de filtros perfeita? Clique no botão "Salvar" (💾), 
     digite um nome (Ex: "Estratégia Segunda-Feira") e dê OK.
   - Para recuperar, basta selecionar o nome na lista suspensa "Carregando...".

[C. EXECUTANDO A INTELIGÊNCIA ARTIFICIAL]
1. Turbo Mode: 
   - Deixe em "OFF" se estiver usando o PC para outras coisas.
   - Ative para "ON" se quiser usar todos os núcleos do seu processador (fará 
     a ventoinha do PC girar mais rápido e achará resultados velozmente).
     
2. Botão "Iniciar IA": 
   - Ao clicar, o Auto-Update verifica a internet. Em seguida, o Log começa a 
     correr. O sistema exibirá G0, G1, G2 (Gerações), mostrando o saldo médio de 
     retorno. Saldo negativo significa prejuízo; positivo significa lucro.

3. Botão "Pausar/Retomar":
   - Clique em Pausar (Fica Amarelo) para congelar os testes e analisar a tela. 
   - Clique em Retomar (Fica Azul) para continuar exatamente de onde parou.

4. Botão "Parar":
   - Encerra a thread atual. O melhor resultado já estará salvo no HD.

[D. ANALISANDO OS RESULTADOS]
Acompanhe os dados em tempo real sem precisar parar a máquina:

1. Heatmap da IA (Raio-X):
   - Observando os 25 quadrados no canto direito inferior, você verá a IA 
     "esquentando" e "esfriando" dezenas. 
   - Cores: Azul Escuro (Descartada) -> Ciano -> Amarelo -> Laranja -> Vermelho (Ouro).

2. Gráfico de Lucro:
   - Clique no menu "Gráfico". A linha verde mostra o histórico de R$ das últimas 
     100 gerações. A linha tracejada vermelha é o Zero (ponto de empate). O 
     objetivo é que a linha verde suba e fique acima da vermelha.

3. Ver Top 3 e Ranking:
   - "Ranking Top 50": Exibe uma lista clicável. Clique em qualquer posição para 
     ver os 33 jogos gerados, os prêmios esperados e a Base de 20 Ouro.
   - "Visualizar Top 3": Uma tela rápida apenas com as 3 melhores matrizes 
     absolutas de todos os tempos.

[E. EXPORTAÇÃO E CIÊNCIA DE DADOS]
- Clique em "Exportar Dataset CSV".
- O sistema gerará o arquivo 'analise_dados_loto.csv' na pasta 'storage'.
- Abra este arquivo no Excel para criar tabelas dinâmicas, gráficos de dispersão 
  ou entregar as apostas para impressão.

================================================================================
                                CONSIDERACÕES FINAIS
================================================================================
* Manutenção: Se a API da Caixa Econômica sair do ar ou a internet cair, o 
  sistema continuará funcionando perfeitamente de forma off-line, utilizando a 
  matemática de cauda longa do arquivo local. 
* O arquivo 'recuperar_base.py' deve ser usado a cada 3 meses ou sempre que você 
  quiser ter certeza absoluta de que a base local foi recarregada por completo.
