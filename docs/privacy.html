🔒 Privacy Policy - Lotofácil Pro

Última atualização: 19 de setembro de 2026

1. Introdução

Lotofácil Pro ("nós", "app") é uma ferramenta educacional de análise estatística para Lotofácil. Respeitamos sua privacidade.

2. Dados Coletados

2.1 Dados automáticos (Firebase e AdMob)

  • ID de dispositivo para anúncios (Google Advertising ID)
  • Dados de uso anonimizados: telas visitadas, tempo no app, gerações realizadas
  • Crash logs para melhorar estabilidade
  • Versão do app, modelo do device, OS

2.2 Dados que NÃO coletamos

  • Nome, email, telefone (a menos que você contate suporte)
  • Localização precisa
  • Dados financeiros (pagamentos via Google Play Billing)
  • Conteúdo pessoal

2.3 Dados que você fornece

  • Dezenas fixas/bloqueadas (armazenadas localmente, não enviadas)
  • Matrizes salvas (local, opcional nuvem se premium)

3. Como usamos

  • Melhorar app e corrigir bugs
  • Mostrar anúncios relevantes (free)
  • Validar compras premium
  • Analytics de uso (Firebase Analytics)

4. Compartilhamento

Compartilhamos dados anonimizados com:

  • Google Firebase (Analytics, Crashlytics)
  • Google AdMob (anúncios)
  • Google Play Billing (compras)

Não vendemos dados para terceiros.

5. Armazenamento

  • Dados locais: Hive/SQLite no device, você pode apagar limpando dados do app
  • Dados nuvem (se premium): Firebase Firestore, criptografado em trânsito e repouso
  • Logs: 90 dias

6. Seus direitos

  • Deletar dados: Configurações > Deletar conta/dados ou email contato
  • Opt-out analytics: Configurações > Desativar analytics
  • Opt-out ads personalizados: Configurações do Google > Ads > Desativar personalização

7. Crianças

App é 12+, não destinado a menores de 12 anos. Não coletamos intencionalmente dados de crianças.

8. Jogo Responsável

Este app é ferramenta educacional, não jogo de azar com dinheiro real. Não garante ganhos. Loteria é jogo de azar, jogue com responsabilidade. +18. Se tem problemas com jogo, procure ajuda: https://www.jogoresponsavel.org.br

9. Não afiliado à Caixa

Não somos afiliados à Caixa Econômica Federal. Resultados obtidos via APIs públicas.

11. Mudanças

12. Consentimento
