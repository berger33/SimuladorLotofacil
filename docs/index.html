🎯 O que é?

O Lotofácil Pro não é um gerador aleatório. É um laboratório de pesquisa que usa:

🧬 Algoritmo Genético

Populações evoluem, elite cruza e muta. Lucro médio sobe a cada geração.

🤖 6 IAs

Atrasômetro, Markov, Ensemble Jedi (XGBoost), Apriori, Auto-Piloto, RL DQN.

🎯 Fechamento Inteligente

20 → 15 com filtros relaxáveis, nunca trava.

✨ Funcionalidades

  • 📊 Dashboard com gráfico convergência (ECG) Top vs Média
  • 🧬 Gerador com Qtd Jogos 10-33, fixas/bloqueadas, 6 filtros, sliders mutação/severidade
  • 🧠 Inteligência: 5 abas com heatmap 5x5 sensorial
  • 🏆 Ranking Top 50 com detalhes, stress tests (histórico, caos 100k, bootstrap), export CSV/PDF, share WhatsApp
  • 👑 Premium: 33 jogos, IA completa, ilimitado, sem ads

📱 App Android

Transformação do simulador desktop CustomTkinter para app Android comercial:

  • Branch Aplicativo: 84 arquivos, core 100% desacoplado, Flutter Pro produção, Kivy MVP, API FastAPI
  • Stack: Flutter Material 3 + Hive + Dio + fl_chart + AdMob + IAP + Firebase
  • Core: 3675 sorteios Caixa, MotorLite com Sharpe, testes 9/9 passando
  • Assets: Ícone 512, feature 1024x500, 8 screenshots 1080x1920 gerados com IA
